# Hubitat CI Toolkit Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to integrate this work. The user explicitly requested GPT-6.1 Sol parallel implementation agents.

**Goal:** Create the approved standalone GitHub template with the entire CI suite and independent watchdog MCP server.

**Architecture:** A runnable generic starter sits beside an immutable source reference. The watchdog is copied without behavior changes; generic client and E2E configuration expose its app-independent tools.

**Tech Stack:** GitHub Actions, Python 3.11+ standard library, Gradle, Groovy 2.4/2.5/3.0, Spock, HubitatCI.

**Spec:** `docs/superpowers/specs/2026-10-11-toolkit-design.md`

## Global Constraints

- Original Hubitat repository remains unchanged.
- Use GitHub Actions for runtime tests, without local dependency installation or test execution.
- Preserve source licenses, commit provenance, and dependency attribution.
- No live hub is configured or contacted during extraction.
- Implementers use separate paths in the new repository.

## Review Focus

- Watchdog documentation must distinguish generic tools from specialized MCP package operations.
- Live workflows must never execute untrusted refs with test-hub credentials.
- Cleanup must report failures and never run after loss of lease ownership.
- HTTP/RPC failures must not leak URLs, tokens, or response contents.
- Copying the template must not activate upstream releases or existing users' hub workflows.
